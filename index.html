First-Time Setup

AI Mock Interview uses Groq Whisper for speech recognition.
A free API key is required to use the app.

1 Go to console.groq.com and create a free account
2 Click API Keys in the sidebar → Create Key
3 Paste your key below — it's stored only on your device

Your key is saved to %AppData%\AI Mock Interview Assistant\config.json
and is never included in any installer or shared file.
